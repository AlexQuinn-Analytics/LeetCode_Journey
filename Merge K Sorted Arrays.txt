You are given a 2D matrix mat[][] of size n x m. Each row in the matrix is sorted in non-decreasing order. Your task is to merge all the rows and return a single sorted array that contains all the elements of the matrix.
Example 1:
Input: mat[][] = [[1,4,5],[1,3,4],[2,6]]
Output: [1,1,2,3,4,4,5,6]
Explanation: Merging all elements from the 3 sorted arrays and sorting them results in: [1,1,2,3,4,4,5,6]

Constraints:
1 ≤ n * m ≤ 10 5
1 ≤ mat[i][j] ≤ 10 6
输入
a two dimension array n * m. For each row, it is sorted. n > 0, m > 0
输出
one dimension array with size n*m and it should be sorted
